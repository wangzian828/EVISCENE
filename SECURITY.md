# Security

Do not post credentials or private traces in issues. Use GitHub's private
vulnerability-reporting channel when available; otherwise request a private
contact without disclosing the vulnerability.

This is a research runtime, not a sandbox. Treat retrieved pages and model
outputs as untrusted. Use a restricted service account and only images you are
authorized to send to configured search/hosting providers and the Baidu OCR API. Local model inference
does not make external tools offline. Judge requests require explicit credentials
and may incur charges.

Rotate exposed keys at their provider. Deleting a file or rewriting Git history
does not revoke a key. Never attach a complete environment dump to a bug report.
